# Reglas de Idioma y Comentarios

1. **Comentarios en el código**: Todos los comentarios dentro del código fuente (TypeScript, JavaScript, CSS, HTML, etc.) deben redactarse exclusivamente en español.
2. **Mensajes de Git**: Los mensajes de commit y descripciones deben redactarse en español (o con prefijos semánticos estándar como `feat:`, `fix:`, `docs:`, pero la descripción siempre en español).
3. **Documentación**: Toda la documentación y notas técnicas se deben redactar en español.
